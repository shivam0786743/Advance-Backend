# DSA Practice — Arrays & Strings (Full Questions + Links)

## Arrays

**1. Two Sum** — https://leetcode.com/problems/two-sum/
Given an array of integers `nums` and an integer `target`, return indices of the two numbers such that they add up to `target`.
`Example: nums = [2,7,11,15], target = 9 → [0,1]`

**2. Best Time to Buy and Sell Stock** — https://leetcode.com/problems/best-time-to-buy-and-sell-stock/
Given an array `prices` where `prices[i]` is the stock price on day `i`, find the max profit from buying on one day and selling later. If no profit possible, return 0.

**3. Move Zeroes** — https://leetcode.com/problems/move-zeroes/
Move all `0`s to the end while maintaining relative order of non-zero elements. In-place.
`Example: [0,1,0,3,12] → [1,3,12,0,0]`

**4. Maximum Subarray** — https://leetcode.com/problems/maximum-subarray/
Find the contiguous subarray with the largest sum, return that sum.
`Example: [-2,1,-3,4,-1,2,1,-5,4] → 6`

**5. Product of Array Except Self** — https://leetcode.com/problems/product-of-array-except-self/
Return array `output` where `output[i]` = product of all elements except `nums[i]`. No division, O(n).

**6. Contains Duplicate** — https://leetcode.com/problems/contains-duplicate/
Return `true` if any value appears at least twice.

**7. Merge Intervals** — https://leetcode.com/problems/merge-intervals/
Merge all overlapping intervals.
`Example: [[1,3],[2,6],[8,10],[15,18]] → [[1,6],[8,10],[15,18]]`

**8. Find All Numbers Disappeared in an Array** — https://leetcode.com/problems/find-all-numbers-disappeared-in-an-array/
Given `nums` of n integers in range `[1,n]`, return all integers in `[1,n]` missing from `nums`. Try without extra space.

**9. Rotate Array** — https://leetcode.com/problems/rotate-array/
Rotate the array right by `k` steps, in-place.
`Example: [1,2,3,4,5,6,7], k=3 → [5,6,7,1,2,3,4]`

**10. 3Sum** — https://leetcode.com/problems/3sum/
Return all unique triplets `[a,b,c]` such that `a+b+c = 0`.

## Strings

**11. Valid Anagram** — https://leetcode.com/problems/valid-anagram/
Return `true` if `t` is an anagram of `s`.
`Example: s="anagram", t="nagaram" → true`

**12. Valid Palindrome** — https://leetcode.com/problems/valid-palindrome/
Check if string is palindrome, considering only alphanumeric chars, ignoring case.
`Example: "A man, a plan, a canal: Panama" → true`

**13. Longest Substring Without Repeating Characters** — https://leetcode.com/problems/longest-substring-without-repeating-characters/
Find length of the longest substring without repeating characters.
`Example: "abcabcbb" → 3`

**14. Group Anagrams** — https://leetcode.com/problems/group-anagrams/
Group an array of strings into anagram groups.
`Example: ["eat","tea","tan","ate","nat","bat"] → [["eat","tea","ate"],["tan","nat"],["bat"]]`

**15. Longest Common Prefix** — https://leetcode.com/problems/longest-common-prefix/
Find the longest common prefix string among an array of strings.
`Example: ["flower","flow","flight"] → "fl"`

**16. Valid Parentheses** — https://leetcode.com/problems/valid-parentheses/
Given a string with `(){}[]`, determine if it's valid (properly matched/ordered).

**17. String Compression** — https://leetcode.com/problems/string-compression/
Compress a char array in-place: repeating chars replaced by char + count. Return new length.
`Example: ["a","a","b","b","c","c","c"] → ["a","2","b","2","c","3"]`

**18. Reverse Words in a String** — https://leetcode.com/problems/reverse-words-in-a-string/
Reverse the order of words; remove leading/trailing/multiple spaces.
`Example: "  the sky is blue  " → "blue is sky the"`

**19. Longest Palindromic Substring** — https://leetcode.com/problems/longest-palindromic-substring/
Return the longest palindromic substring in `s`.
`Example: "babad" → "bab" or "aba"`

**20. Minimum Window Substring** — https://leetcode.com/problems/minimum-window-substring/
Return the minimum window substring of `s` containing every character of `t` (with duplicates).
`Example: s="ADOBECODEBANC", t="ABC" → "BANC"`
